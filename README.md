# 広昌会協同組合 公式サイト

技能実習生・特定技能外国人の受け入れを支援する監理団体・登録支援機関です。
国際人材の受け入れと育成を通じて、日本と海外諸国の架け橋となることを使命としています。

**サイト** → **<https://koshokai.github.io/jp/>**

## このリポジトリについて

GitHub Pages で公開している静的サイトです。ビルド工程はなく、`main` ブランチの
HTML がそのまま配信されます。

```
index.html          トップページ
overview.html       組合概要
ginou.html          技能実習
tokutei.html        特定技能
ukeire.html         受け入れの流れ
training.html       研修センター
jinzai.html         人材情報
mitumori.html       一括見積り
qa.html             Q&A
sending*.html       送り出し機関
interview.html      専門家インタビュー
denryoku.html       電力提供
contact.html        お問い合わせ
style.css           共通スタイル
photos/             画像
sitemap.xml         検索エンジン向けサイトマップ
```

`index_old.html` は旧版のため `noindex` を指定しています。
